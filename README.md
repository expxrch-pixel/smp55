## 🌟 จุดเด่นและฟีเจอร์เด่น
1. **หน้าแรก (Home - `index.html`)**:
   - แบนเนอร์สไตล์มินิมอลหรูหรา โทนสี **Jet Black & Pure White**
   - โลโก้ตราประจำตระกูล **OTF 3D หมุนได้รอบทิศทาง** (`3D Rotating Emblem`)
   - คำขวัญประจำบ้าน: *"LOYALTY OVER ROYALTY — FAMILY FIRST • RESPECT EARNED • NEVER DIVIDED"*
   - แถบสถานะระบบและจำนวนสมาชิกรวม
   - ปุ่มทางลัดไปยังหน้ารายชื่อสมาชิก และระบบจัดการสมาชิก

2. **หน้ารายชื่อสมาชิก (Members - `members.html`)**:
   - **Summary Tiles**: สรุปยอดสมาชิกแบบ Real-time แยกตามระดับ (ทั้งหมด, OWNER, LEADER, BIGSUPPORT, MEMBERS) ในโทนดำ-ขาว แพลทินัม
   - **ระบบค้นหาแบบทันที**: ค้นหาตามชื่อ, ฉายา, ยศ หรือคำคมได้ทันที
   - **ตัวกรองระดับยศ**: สลับดูเฉพาะ OWNER, LEADER, BIGSUPPORT หรือ MEMBERS
   - **โครงสร้างการแสดงผลตามลำดับชั้น**:
     - **OWNER**: การ์ด VIP พรีเมียมขนาดใหญ่ ขอบขาวสะท้อนแสง พร้อมแบนเนอร์และคำคมประจำตัว
     - **LEADER**: การ์ดระดับแกนนำ 3 คอลัมน์ โดดเด่นด้วยโทนสีขาวเงินแพลทินัม
     - **BIGSUPPORT**: การ์ดระดับผู้สนับสนุนหลัก โทนสีเทาเงิน Steel Grey
     - **MEMBERS**: การ์ดสมาชิกกะทัดรัด พร้อมไฟแสดงสถานะ Online/Offline
   - **Profile Modal**: คลิกที่การ์ดสมาชิกเพื่อเปิดป๊อปอัพโปรไฟล์ขนาดใหญ่ ดูรูป Banner, Avatar, ข้อมูลบ้าน, วันที่เข้าร่วม, คำคม, และปุ่มติดต่อ Discord / Facebook / Steam

3. **ระบบจัดการหลังบ้าน (แยกจากเว็บปกติ - `admin.html`)**:
   - **แยกออกจากหน้าเว็บหลักอย่างสมบูรณ์**: ผู้ชมทั่วไปในหน้า `index.html` และ `members.html` จะเห็นเฉพาะเมนู Home และ Members เท่านั้น จะไม่มีปุ่มหรือเมนูให้กดเข้าจัดการ
   - **ระบบล็อคความปลอดภัย (Security PIN Gate)**: เข้าใช้งานผ่านไฟล์ `admin.html` โดยต้องกรอกรหัส PIN ก่อนเข้าสู่ระบบ (รหัสเริ่มต้น: **`1688`**)
   - **คีย์ลัดลับ (Secret Hotkey)**: สามารถกดคีย์ลัด `Ctrl + Shift + A` ได้จากหน้าเว็บเพื่อเปิดหน้าระบบจัดการทันที
   - **เพิ่ม/แก้ไข/ลบสมาชิก**: ตั้งชื่อ, เลือกยศ, กำหนดตำแหน่งเฉพาะ, ใส่รูปโปรไฟล์, แบนเนอร์, สถานะ, ช่องทางติดต่อ
   - **เปลี่ยนรหัสผ่าน**: สามารถเปลี่ยนรหัส PIN ของหลังบ้านได้ตลอดเวลาในแท็บตั้งค่า
   - **ระบบสำรองข้อมูล (JSON Backup & Restore)**: ดาวน์โหลดไฟล์ JSON เก็บไว้ หรือนำเข้าเพื่อกู้คืนข้อมูลได้ทุกเมื่อ

4. **ระบบเสียงและบรรยากาศ (Audio & Atmosphere)**:
   - **Logo Spin Sync**: ตราสัญลักษณ์ 3D จะหมุนรอบทิศทาง **เฉพาะเมื่อเปิดเพลงเท่านั้น** เมื่อเพลงหยุด ตราจะหยุดหมุน และสามารถคลิกที่ตรา 3D หรือกดปุ่ม `Spacebar` เพื่อสั่งเปิด/ปิดเพลงได้ทันที
   - **Floating Music Player**: เครื่องเล่นเพลงมินิมอลติดมุมจอด้านล่างสีดำ-ขาว พร้อมกราฟิก Audio Visualizer สีขาว ปุ่ม Play/Pause และปุ่มย่อหน้าต่าง
   - **คำสั่งและคำอธิบายภาษาไทย**:
     - **คำสั่งและกฎเหล็กครอบครัว OTF**: ลำดับการบังคับบัญชา, ความภักดี, ร่วมรบไม่ทิ้งใครไว้ข้างหลัง, ให้เกียรติและรักษาชื่อเสียง
     - **คำอธิบายโครงสร้างตำแหน่ง**: อธิบายหน้าที่ชัดเจนของ OWNER, LEADER, BIGSUPPORT และ MEMBERS
     - **คำสั่งคีย์ลัดในเว็ปไซต์**: ปุ่ม Spacebar เปิด/ปิดเพลง, `Ctrl + Shift + A` เข้าสู่ห้องควบคุมลับ, ระบบค้นหาทันที และคลิกการ์ดดูโปรไฟล์
   - **Ambient Particles Canvas**: เอฟเฟกต์ละอองประกายดาวสีขาว (Monochrome Stardust) ลอยบนหน้าจออย่างนุ่มนวล
   - **Entry Sequence**: แอนิเมชันเปิดตัวตราสัญลักษณ์ "OTF" ก่อนเข้าสู่เว็บไซต์

## 🌐 วิธีนำขึ้นออนไลน์ฟรี (ให้ได้ลิงก์เหมือน `tataros168.vercel.app`)

### วิธีที่ 1: อัปโหลดผ่าน Vercel (แนะนำ - ง่ายที่สุด)
1. สมัครใช้งานที่ [vercel.com](https://vercel.com)
2. ลากโฟลเดอร์ `otf-onythefamily` ไปวางที่หน้าแดชบอร์ดของ Vercel หรือเชื่อมต่อผ่าน GitHub
3. กด **Deploy** จะได้โดเมนฟรี เช่น `otf-onythefamily.vercel.app` ใช้งานได้ทันที

### วิธีที่ 2: อัปโหลดผ่าน Netlify
1. สมัครใช้งานที่ [netlify.com](https://netlify.com)
2. ไปที่แท็บ **Sites** แล้วลากโฟลเดอร์ `otf-onythefamily` ไปวางในช่อง "Drag and drop your site output folder here"
3. รอ 10 วินาที จะได้ URL เว็บไซต์พร้อมแชร์ให้เพื่อนๆ ในกลุ่มได้ทันที
